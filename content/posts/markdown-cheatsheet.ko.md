블로그를 쓰는 데 필요한 Markdown은 사실 얼마 되지 않습니다. 아래 내용이면 95%의 상황을 커버하고, 그대로 복사해서 쓸 수 있습니다.

## 제목

`#`의 개수가 계층을 나타냅니다. `#`은 1단계, `##`은 2단계입니다. **본문에서는 2단계 제목부터 사용하세요.** 1단계는 글 제목을 위해 남겨 둡니다.

```markdown
## 이것은 2단계 제목입니다
### 이것은 3단계 제목입니다
#### 이것은 4단계 제목입니다
```

## 강조

```markdown
**굵게**
*기울임*
~~취소선~~
`인라인 코드`
```

결과: **굵게**, *기울임*, ~~취소선~~, `인라인 코드`.

## 목록

순서 없는 목록은 `-` 또는 `*`, 순서 있는 목록은 `1.`을 씁니다:

```markdown
- 첫 번째 항목
- 두 번째 항목
  - 중첩 항목 (앞에 공백 두 칸)

1. 첫 번째 단계
2. 두 번째 단계
```

## 링크와 이미지

```markdown
[링크 텍스트](https://example.com)
![이미지 설명](이미지 주소)
```

이미지는 글과 같은 이름의 폴더에 두고 상대 경로로 참조하는 편이 좋습니다. 그러면 이미지가 글과 함께 따라옵니다.

## 인용

```markdown
> 이것은 인용문입니다.
> 여러 줄로 쓸 수 있습니다.
```

## 코드 블록

백틱 세 개로 감싸고 바로 뒤에 언어 이름을 적으면 코드가 자동으로 강조되고, 오른쪽 위에 복사 버튼이 나타납니다:

````markdown
```python
def hello(name):
    print(f"Hello, {name}!")
```
````

## 표

```markdown
| 왼쪽 정렬 | 가운데 | 오른쪽 정렬 |
| :--- | :---: | ---: |
| 내용 | 내용 | 내용 |
```

## 구분선

하이픈 세 개를 한 줄에 단독으로 쓰면 구분선이 됩니다:

```markdown
---
```

## 두 가지 작은 요령

**줄바꿈**: Markdown에서는 단순한 줄바꿈이 줄바꿈으로 처리되지 않습니다. 강제로 줄을 바꾸려면 줄 끝에 공백 두 칸을 넣거나, 그냥 빈 줄을 한 줄 넣어 문단을 나눕니다.

**특수 문자**: `*`나 `#`을 문법이 아니라 그대로 표시하고 싶다면 앞에 백슬래시를 붙여 `\*`라고 씁니다.
