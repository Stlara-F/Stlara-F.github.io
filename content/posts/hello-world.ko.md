이 블로그의 첫 글입니다. 그냥 "Hello World"라고 쓰는 대신, 이 블로그가 기술적으로 어떻게 구성되어 있는지 먼저 정리해 둡니다 — 나중에 다시 돌아볼 때 도움이 될 테니까요.

## 기술 선택

| 항목 | 선택 | 이유 |
| --- | --- | --- |
| 정적 사이트 생성기 | Hugo | Go로 작성되어 빌드가 매우 빠르고, 수천 개의 글도 몇 초 만에 처리 |
| 테마 | Blowfish | Tailwind CSS 기반으로 기본 디자인이 좋고, 커스텀 스타일을 넣기도 쉬움 |
| 호스팅 | GitHub Pages | 무료, 광고 없음, HTTPS와 커스텀 도메인 지원 |
| 버전 관리 | Git | 글마다 히스토리가 남아 잘못 수정해도 언제든 되돌릴 수 있음 |

## 왜 정적 사이트인가

전통적인 블로그 시스템(예: WordPress)에서는 방문이 있을 때마다 서버가 데이터베이스를 조회해 페이지를 조립합니다. 정적 사이트는 모든 페이지를 빌드 단계에서 HTML 파일로 미리 생성하기 때문에 요청에 바로 응답할 수 있고, 데이터베이스가 없으므로 느려지거나 부하에 무너질 일도 없습니다.

그 대가로, 동적 기능(댓글, 좋아요, 방문 통계)은 서드파티 서비스에 의존해야 합니다. 개인 블로그 수준에서는 이 정도 대가가 보통 충분히 값어치를 합니다.
