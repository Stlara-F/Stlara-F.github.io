これがこのブログの最初の記事です。「Hello World」と書く代わりに、まずこのブログの技術的な構成を説明しておきます。後から振り返るときにも役立ちます。

## 技術選定

| 項目 | 選択 | 理由 |
| --- | --- | --- |
| 静的サイトジェネレーター | Hugo | Go 製でビルドが非常に速く、数千記事でも秒単位で完了 |
| テーマ | Blowfish | Tailwind CSS ベースで、デフォルトの見た目が良く、カスタムスタイルも入れやすい |
| ホスティング | GitHub Pages | 無料・広告なし・HTTPS と独自ドメインに対応 |
| バージョン管理 | Git | 記事ごとに履歴が残り、失敗してもすぐ元に戻せる |

## なぜ静的サイトなのか

従来のブログシステム（WordPress など）では、アクセスがあるたびにサーバーがデータベースを照会してページを組み立てます。静的サイトでは、すべてのページをビルド時に HTML ファイルとして生成するため、リクエストには直接応答できます。データベースが不要なので、遅くなったり負荷で落ちたりする心配もありません。

その代償として、動的な機能（コメント、いいね、アクセス解析）にはサードパーティのサービスが必要です。個人ブログにとって、この代償は通常とても割に合います。
