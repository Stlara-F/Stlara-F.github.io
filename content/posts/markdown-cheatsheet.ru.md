Для ведения блога Markdown нужен совсем небольшой. Всё, что ниже, покрывает примерно 95 % случаев, и это можно копировать и править под себя.

## Заголовки

Уровень задаётся количеством `#`: `#` — первый уровень, `##` — второй. **В тексте начинайте со второго уровня** — первый оставлен для заголовка статьи.

```markdown
## Это заголовок второго уровня
### Это заголовок третьего уровня
#### Это заголовок четвёртого уровня
```

## Выделение

```markdown
**полужирный**
*курсив*
~~зачёркнутый~~
`строчный код`
```

Результат: **полужирный**, *курсив*, ~~зачёркнутый~~, `строчный код`.

## Списки

Маркированные списки используют `-` или `*`, нумерованные — `1.`:

```markdown
- Первый пункт
- Второй пункт
  - Вложенный пункт (с отступом в два пробела)

1. Первый шаг
2. Второй шаг
```

## Ссылки и изображения

```markdown
[текст ссылки](https://example.com)
![подпись к изображению](адрес изображения)
```

Изображения лучше хранить в папке с тем же именем, что и статья, и подключать по относительному пути — тогда они переезжают вместе со статьёй.

## Цитаты

```markdown
> Это цитата.
> Она может занимать несколько строк.
```

## Блоки кода

Оберните код в три обратных апострофа и укажите сразу после них язык — код подсветится сам, а справа сверху появится кнопка копирования:

````markdown
```python
def hello(name):
    print(f"Hello, {name}!")
```
````

## Таблицы

```markdown
| По левому краю | По центру | По правому краю |
| :--- | :---: | ---: |
| Текст | Текст | Текст |
```

## Разделитель

Три дефиса на отдельной строке — это разделитель:

```markdown
---
```

## Две маленькие хитрости

**Перенос строки**: одиночный перенос в Markdown не считается переносом. Чтобы он был принудительным, поставьте два пробела в конце строки — или просто оставьте пустую строку и начните новый абзац.

**Специальные символы**: если нужно, чтобы `*` или `#` отображались буквально, а не как разметка, поставьте перед ними обратный слеш — напишите `\*`.

---

Этого в основном достаточно. Во время письма не нужно специально думать о разметке — с практикой она запоминается сама.
