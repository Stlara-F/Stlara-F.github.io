ブログを書くのに必要な Markdown はごくわずかです。以下で 95% の場面をカバーできます。そのままコピーして使ってください。

## 見出し

`#` の数が階層を表します。`#` が見出し1、`##` が見出し2です。**本文では見出し2から使い始めてください**。見出し1は記事タイトル用に取ってあります。

```markdown
## これは見出し2です
### これは見出し3です
#### これは見出し4です
```

## 強調

```markdown
**太字**
*斜体*
~~取り消し線~~
`インラインコード`
```

結果：**太字**、*斜体*、~~取り消し線~~、`インラインコード`。

## リスト

箇条書きは `-` か `*`、番号付きリストは `1.` を使います：

```markdown
- 1つ目の項目
- 2つ目の項目
  - 入れ子の項目（前に空白2つ）

1. 手順1
2. 手順2
```

## リンクと画像

```markdown
[リンクの文字](https://example.com)
![画像の説明](画像のアドレス)
```

画像は記事と同じ名前のフォルダに置き、相対パスで参照するのがおすすめです。そうすれば画像も記事と一緒に移動できます。

## 引用

```markdown
> これは引用です。
> 複数行にわたって書けます。
```

## コードブロック

バッククォート3つで囲み、その直後に言語名を書くと、コードが自動でハイライトされ、右上にコピーボタンが出ます：

````markdown
```python
def hello(name):
    print(f"Hello, {name}!")
```
````

## 表

```markdown
| 左寄せ | 中央 | 右寄せ |
| :--- | :---: | ---: |
| 内容 | 内容 | 内容 |
```

## 区切り線

ハイフン3つを単独の行に書くと区切り線になります：

```markdown
---
```

## 小さなコツ2つ

**改行**：Markdown では単純な改行は改行として扱われません。強制的に改行したいときは行末に空白を2つ入れるか、いっそ空行を1行入れて段落を分けます。

**特殊文字**：`*` や `#` を記法としてではなくそのまま表示したいときは、その前にバックスラッシュを付けます。`\*` と書きます。
