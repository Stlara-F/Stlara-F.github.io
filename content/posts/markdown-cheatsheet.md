写博客用到的 Markdown 语法其实很少。下面这些覆盖了 95% 的场景，可以直接复制去改。

## 标题

用 `#` 的数量表示层级，`#` 是一级标题，`##` 是二级。**正文里从二级标题开始用**，一级标题留给文章标题。

```markdown
## 这是二级标题
### 这是三级标题
#### 这是四级标题
```

## 强调

```markdown
**加粗**
*斜体*
~~删除线~~
`行内代码`
```

效果：**加粗**、*斜体*、~~删除线~~、`行内代码`。

## 列表

无序列表用 `-` 或 `*`，有序列表用 `1.`：

```markdown
- 第一项
- 第二项
  - 嵌套项（前面空两格）

1. 第一步
2. 第二步
```

## 链接与图片

```markdown
[链接文字](https://example.com)
![图片说明](图片地址)
```

图片建议放在和文章同名的文件夹里，用相对路径引用，这样文章的图片会跟着文章一起走。

## 引用

```markdown
> 这是一段引用。
> 可以写多行。
```

## 代码块

用三个反引号包起来，并在开头写上语言名称，代码就会自动高亮，右上角还会出现复制按钮：

````markdown
```python
def hello(name):
    print(f"Hello, {name}!")
```
````

## 表格

```markdown
| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| 内容 | 内容 | 内容 |
```

## 分隔线

三个短横线单独一行，就是一条分隔线：

```markdown
---
```

## 两个小技巧

**换行**：Markdown 里单个换行不算换行，想强制换行就在行尾敲两个空格，或者直接空一行分段。

**特殊符号**：如果想让 `*` 或 `#` 原样显示而不被当成语法，在它前面加一个反斜杠，写成 `\*`。
